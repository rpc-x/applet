📐 标后保函小程序 UI 原型说明

核心页面：首页、发布需求、机构筛选、一键比价、订单、理赔、保函验真、个人中心

业务流程：填写项目信息 → 设置机构筛选条件 → 一键发布竞价 → 机构在线报价 → 客户比价选定 → 出函 → 订单跟踪

机构筛选维度：机构类型（银行/担保/保险/金融）、担保性质（融资/非融资）、注册资本、实缴情况、国企背景、即索赔付格式、服务区域

订单状态：全部、竞价中、出函中、已出函、已退保、已取消（点击 Tab 可筛选）；已出函订单支持验真、理赔、下载保函

操作指引：点击底部 Tab 切换页面，点击快捷入口和列表项可跳转至对应功能页，筛选页支持多维度条件组合
